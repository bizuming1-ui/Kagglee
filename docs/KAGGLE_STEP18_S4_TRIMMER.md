- 输出 `stats.trim`：输入/返回/领先丢弃/精确零尾丢弃/取消丢弃/缓存和守恒。返回样本不等于已播放样本；finish返回后取消的样本另记 `cancelled_after_trim_samples`。最终发帧前重查取消，但不宣称线程事件与声卡播放原子化。
- 输入只读、非连续、非有限样本和float32极值有明确测试；阈值平方采用float64，非有限等价置零。
