## 基线与方法

初始提交 `2cdbd47` 只有 `README.md`（标题 Kagglee），没有应用代码、测试或依赖。因此前三轮基线审查提出的是实现约束，而不是虚构90个既有缺陷。实施后按以下清单回查源码与对应实验。对于不适用项或边界，明确记录，不宣称“所有情况零错误”。

技术方案：Node.js 原生 HTTP + 原生浏览器 JavaScript/HTML/CSS。没有计算密集型需求，不引入无收益的多语言运行环境。开发测试工具与生产运行隔离。

## 实际发现与修复

1. 初始环境无法访问 Playwright CDN：改用 npm 分发的 Chromium，不把安装失败算测试通过。
2. 极简 Linux 缺 NSS 库：使用浏览器包附带库，放入 node_modules，不把二进制纳入项目。
3. 浏览器包默认包含不适合隔离测试的禁用 Web Security 参数：测试配置明确移除，保留浏览器安全模型。
4. 文件图标参与可访问名称导致精确文件名查找失败：图标 aria-hidden，标签增加明确 aria-label。
5. 连接日志端口前缓冲只保留开头日志：改为滚动保留最近200条。
6. 截图中文字为方框：随项目提供本地 Noto Sans SC 和许可证，增加实际字体加载测试。
7. 完整HTML里的本地style.css/script.js引用可能误请求工作台资源：解析HTML，精准删除这两种引用后统一注入编辑文件；补测只执行一次与文档语言保留。

## 后续需求：自命名空白文件

用户希望自行命名文件，并自行复制粘贴内容。新增：

- 顶部工具栏“＋ 新建文件”对话框：文件名由用户输入，内容严格为空，不填充生成代码。
- 新文件与原有文件使用同一编辑器、保存按钮及原子版本存储，中文名、空内容和原始文本均可落盘恢复。
- 自命名文件可重命名，内容不变；只有再次保存才修改当前磁盘版本，历史版本保留旧名称。三个预设文件不能重命名，以保护原有运行流程。
- 最多32个文件（含预设3个），总内容仍限制1 MiB。前后端共用命名规则：拒绝路径、重名（大小写不敏感）、保留字、过长名称与原型键。
- 项目读取枚举当前快照中的真实普通文件，不再只读取预设三个文件。旧三文件版本无须迁移即可恢复。
- 选中自命名HTML后可独立运行；只有明确引用style.css/script.js时才加载伴随文件，避免默认示例污染用户页面。其他自命名文本仅编辑保存。
- 动态标签支持键盘切换；手机端也可新建、命名、粘贴和保存。恢复示例保留自命名文件。

验证：`npm test` 更新为30项，连续执行3遍全部通过；`npm run test:e2e` 更新为33项，全部通过（包括原有26项回归）。新增7项自命名文件场景另行重复3遍：`npm run test:e2e -- --grep 自命名空白文件 --repeat-each=3`，最终 **21 passed (1.1m)**，0失败、0跳过。
